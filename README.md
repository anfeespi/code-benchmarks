# code-benchmarks

In-house execution-graded Python code benchmark (48 problems, 6 categories x 8) used to
compare models for coding tasks. Rebuilt in September 2026 as **v4** after the July runners
were lost; problems and every stored model output come from the Braintrust project
`code-benchmarks`, and this repo now persists the test suite so it cannot be lost again.

- `data/problems/code-bench-v2.json` — the 48 problems (prompt, entry point, canonical solution)
- `tests/<slug>.json` — v4 test cases; `expected` values are generated from the canonical solution
- `data/outputs/` — model outputs (July v1/v2/v2r/v3 from Braintrust, v4 fresh runs)
- `codebench/harness.py` — sandboxed execution + scoring (checker / tests_ratio / pass)
- `codebench/build_tests.py` — author tests, fill expected values
- `codebench/calibrate.py` — agreement of the v4 suite with the stored July scores
- `codebench/generate.py` — fresh generations (Anthropic API / OpenRouter), refusals tracked
- `codebench/score.py`, `codebench/publish.py` — score a run, publish to Braintrust

Typical flow: `build_tests show <category>` -> write `tests/<slug>.json` -> `build_tests expect <slug>`
-> `calibrate --category <c>` -> `generate` -> `score --write` -> `publish`.

## Agentic Go track (`agentic-go-v1`)

Measures engineering work with tools in a Go payments microservice instead of
single-function answers.

- `agentic/go-payments/` — base module (stdlib Go 1.22+): money/rounding, payment state
  machine with partial refunds, in-memory repository, idempotency store, webhook
  dispatcher with retries over an injectable clock, net/http API. Visible tests included.
- `agentic/tasks/<id>/` — 18 tasks: `task.json` (Jira-style ticket), `start.patch`
  (starting state), `solution.patch` (reference fix), `hidden/` (acceptance tests the
  model never sees). Patches are generated by `agentic/tasks/author.py`.
- `codebench/agentic.py` — tool loop (list_files, read_file, write_file, apply_edit,
  run restricted to go build/test/vet + gofmt, finish), budgets (40 tool calls, 150k-token
  context), grading with `go test -race -count=1 ./...` plus broken-visible-test, vet and
  gofmt checks. Providers: OpenRouter and Bedrock converse.

```
uv run --python 3.12 python -m codebench.agentic verify      # solutions pass, start states fail
uv run --python 3.12 python -m codebench.agentic run --provider openrouter \
    --model google/gemini-3.8-flash --tag gemini-3.8-flash --key-file /tmp/openrouter-key.txt
uv run --python 3.12 --with boto3 python -m codebench.agentic run --provider bedrock \
    --model global.anthropic.claude-sonnet-5-5 --aws-profile agentland-dev --region us-east-1 \
    --tag sonnet-5.5-bedrock --jobs 3
```

Outputs: `data/agentic/runs/<tag>/<task>.jsonl` (full transcripts) and
`data/agentic/outputs/agentic-go-v1__<tag>.json` (per-task pass, hidden tests, tool calls,
tokens, cost, wall time, broken visible tests, vet/gofmt).
